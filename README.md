# AI Stack

MGD's AI Stack plugins

## Installation

```bash
# Add marketplace
claude plugins marketplace add --scope user https://github.com/ducminhgd/aistack
# or
claude plugins marketplace add --scope user ./path/to/local/aistack

# install plugins
claude plugin install mgd-swe@mgd-marketplace
claude plugin install mgd@mgd-marketplace
claude plugin install mgd-product@mgd-marketplace
```
