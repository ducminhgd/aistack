# Auto-invoke workflows

## List of Skills

| Name | Command | Purpose | Who should use it |
| --- | --- | --- | --- |
| `product-ideation` | `product-ideation` | Brainstorm product ideas, critique concepts, improve product direction, or rewrite PRDs, specs, and user stories into clearer requirements. | Product managers, founders, designers, analysts, and engineers working on product definition or feature scope. |
| `project-planning` | `project-planning` | Plan a project or product delivery, break down work into structured items (Features → Epics → Tasks → Sub-tasks), create backlogs, estimate effort, map dependencies, and produce sprint plans. | Engineering managers, tech leads, and developers who need to scope and plan delivery of a feature, system, or full product. |
| `swe-implement` | `swe-implement` | Implement features, write production-grade code, refactor, add tests, fix bugs, or review code. Produces clean, testable, removable code following Clean Architecture principles with full implementation guidance. | Software engineers implementing tasks from designs, tickets, or specs — or reviewing/improving existing code. |
| `swe-code-review` | `swe-code-review` | Review code, diffs, or PRs with structured feedback across correctness, security, testability, removability, readability, performance, and consistency. Produces a verdict (Approved / Changes Requested / Blocked) with severity-labelled findings. | Software engineers reviewing pull requests, checking code quality, or getting feedback before merging. |
